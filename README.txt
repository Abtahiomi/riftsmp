RIFT SMP STATIC WEBSITE

Open index.html in a browser or upload this folder's contents to static hosting.

The supplied RIFT SMP logo is stored at assets/rift-logo.png and used unchanged in the navigation, hero, and footer. Keep the asset in that location when publishing.

Edit the products object in script.js to update shop products. Rules and other copy live in index.html. Every purchase button opens the specified Discord invite in a new tab. Gallery panels are CSS placeholder scenes; replace their scene elements with your server screenshots. The server card is a static placeholder and can be connected to a server-status API later.
