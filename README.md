# RIFT SMP Website

A static, responsive website for the RIFT SMP Minecraft server. Open `index.html` locally or enable GitHub Pages from the repository's `main` branch and root directory.

## Brand assets

- `assets/logo.png` is the supplied logo, used without editing.
- `assets/banner.png` is the supplied world banner used in the hero and world feature section.

## Shop and links

Shop items are edited in `script.js`. The RANKS and MONEY categories link all purchase buttons to the RIFT SMP Discord invite; the site does not implement payment processing. The server IP copy button copies `riftsmp.fun`. YouTube and Discord URLs are set in `index.html`.

The server status is intentionally not represented as live; connect a status API before displaying online/player counts.
